# UX/UI Review — Frontend + Admin (2026-10-04)

Method: Playwright screenshots (desktop 1440, mobile 390, all 15 admin tabs), two independent
vision reviews, pixel/contrast analysis, and live DOM probes. Scores before fixes:
**frontend 4–6/10, admin 6/10** → after fixes, re-verified (see Fixed section).

## Recommendations (not done — needs your call, Bala)

1. **Inline form validation instead of `alert()`** — works today, but native dialogs feel dated; inline field errors would be more "minimal/modern" (~8 call sites in `main.js`).
2. **Self-host icons + fonts** (Material Symbols, Fraunces/Manrope) — removes the only CDN dependency; the one capture that failed showed how structural the breakage is.
3. **Audit Logs: filters + pagination** (currently one 2,800px scroll).
4. **Icon/label pairs**: Pricing uses the `payments` glyph while Payments uses `credit_card` — swap to less confusable icons.
5. **Brand copy**: logo says "Singapore Tour Booking", H1/footer say "STB Singapore", tagline "Majestic Hospitality Since 2014" — confirm this mix is intended.
6. **`brand.email = bala@tensketch.com`** is the reply-to on booking emails — consider `info@`.
7. Mobile header has no persistent "Book" button (desktop does).
8. Tiny ~10px uppercase labels — bump to ≥12px.
