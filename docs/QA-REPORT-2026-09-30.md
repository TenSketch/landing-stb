## Findings & disposition

### 1. [Medium] Session cookies missing `Secure` flag — FIXED
- **Repro:** `POST https://api.singaporetourbooking.com/api/auth/login` → `Set-Cookie: stb_customer_session=…; HttpOnly; SameSite=Strict` (no `Secure`). Admin cookie had the same issue (`secure: isProd` and `NODE_ENV` is unset).
- **Risk:** cookie can be attached to a subsequent plain-HTTP request before the nginx→HTTPS redirect; mitigated by HSTS preload but not eliminated.
- **Fix:** `secure: true` on customer cookie (2 sites) and admin `cookieOpts`. `NODE_ENV` intentionally NOT flipped to production (would change cookie `domain`/`secure` semantics app-wide). `domain`/`sameSite` untouched.
- **Verify:** audit C-cookies 4/4 pass; e2e login flow still green.

### 2. [Low] Unknown `/api/*` returned SPA HTML with 200 — FIXED
- **Repro:** `GET /api/definitely-not-a-route-xyz` → `200 text/html` (public index.html via the `app.get("*")` fallback).
- **Fix:** JSON 404 handler `app.use("/api", …)` placed after all API routes, before the SPA fallback.
- **Verify:** `GET /api/definitely-not-a-route-xyz` → `404 {"error":"Not found"}` (direct + live).

### 3. [False alarm — harness bug] "Login rate limit never returns 429"
- Original probe used a **different email per attempt**; the limiter keys on email → never accumulated.
- Re-probe with one fixed email: `401 ×5 → 429` ✓. **App unchanged**, harness corrected.

### 4. [Medium] `/api/estimate` 500 without GOOGLE_MAPS_API_KEY — FIXED
- **Repro:** `POST /api/estimate` with `{bookingType:'One Way', origin:{lat,lng}, destination:{lat,lng}}` → 500 when the key env var was empty, even though coordinates were supplied.
- **Fix:** coordinate fallback in `lib/handlers.js` — haversine distance × 1.3 road factor, 40 km/h duration estimate, then the SAME admin pricing engine (base fare + per-km + minimums + surcharges). Response marked `distanceSource:"approx"`. placeId-only inputs (impossible without Google autocomplete anyway) get a clear 400. The Google path is unchanged, so adding a key later upgrades estimates automatically.
- **Verify:** live POST → `200` (22.24 km Changi→MBS; 4-Seater SGD 88.92, 6-Seater 100.59); e2e `3-estimate` 3/3; suite 90/90.
